# NapCat QQ 管理员转发

日常只需使用根目录的三个入口，开发板后台程序不需要电脑持续运行。

| 入口 | 用途 |
| --- | --- |
| [打开正在运行的QQ管理页.cmd](打开正在运行的QQ管理页.cmd) | USB连接后打开当前WebUI；含复制管理Token按钮 |
| [填写QQ自动登录账号密码.cmd](填写QQ自动登录账号密码.cmd) | 保存到开发板私密目录，下次需要启动QQ时用于密码回退 |
| [填写QQ管理员转发配置.cmd](填写QQ管理员转发配置.cmd) | 保存电脑上的转发目标配置；后续还需同步到开发板 |

## 文件分类

| 文件夹 | 内容 |
| --- | --- |
| [docs](docs) | 使用说明、可靠转发、WebUI、存储清理及密码登录说明 |
| tools/windows | 三个入口实际调用的电脑端程序 |
| board/relay | QQ管理员消息筛选、持久化队列、重试及QQ守护源码 |
| board/maintenance | 存储清理、消息库轮换、密码设置和启动控制源码 |
| [tests](tests/README.md) | 开发板Linux测试及运行方式 |

常用说明：[可靠转发](docs/可靠转发使用说明.md)、[WebUI访问](docs/WebUI访问与定时清理.md)、[密码配置](docs/QQ密码自动登录说明.md)、[原生消息库清理](docs/原生消息库定时清理.md)、[存储策略](docs/存储维护策略.md)。

新增规则见 [表情过滤与连续发言合并](docs/表情过滤与连续发言合并.md)：200000002 群过滤表情，同一管理员短文本静默 5 秒、最长收集 20 秒；普通配图与说明文字合为一条通知。

自用版本保留与换板准备见 [换板恢复清单](docs/换板恢复清单.md)。保留当前B站共享依赖即可，不要求先改造成独立产品；私密配置和待发送队列需要另外安全备份。

密码保存传输超时已修复，并用测试数据完成USB端到端验证。请关闭旧配置窗口，再从根目录入口重新打开。保存不代表QQ密码已通过服务器验证，验证码/手机确认仍可能需要本人操作。

原15分钟扫码验证程序已归档；正式服务运行时不要再启动第二个QQ实例。真实密码、Webhook、登录数据和聊天数据库不在本交付目录中。

## GitHub 源码副本

用于自用版本记录和更换开发板时恢复；不是一键安装包。此副本不含 archive、安装包、凭据或运行数据。

公开示例群号为 `200000001`、`200000002`，并非实际监听群。Windows USB 工具中的 `C:\path\to\adb.exe` 和 `YOUR_ADB_SERIAL` 需替换为自己的 ADB 路径与 `adb devices` 显示的设备编号。Python 路径与私密配置目录也需按新电脑检查。

当前验证：75 项组件测试通过。规则包括表情过滤、同一管理员 5 秒静默/最长收集 20 秒的持久化合并，以及文字配图同条飞书通知。超长内容仍分批，普通图片缺少表情标记时会保留。

运行依赖本仓库的 `deploy/h616` B站部署：可信时间保护与飞书图片上传仍共享该部分代码。真实配置、队列与登录态需另外私密备份。
