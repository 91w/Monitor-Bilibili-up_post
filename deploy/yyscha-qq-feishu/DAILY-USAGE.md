# 日常操作

双击 `00-menu.cmd`：1 登录并加密同步，2 查询/重试同步，3 查看板端队列，4 查看板端 Cookie 元数据，5 打开本文。

更新 Cookie：正常登录或导入 Cookie → 点击“验证并加密上传” → 查询/重试同步 → 以“开发板已确认验证并应用”为完成。只显示密文上传代表 COS 收到，不代表板端已应用。不要把 Cookie 手动上传到控制台或聊天。

登录同步和签名回执查询不需要 USB，但要求两端联网、COS 身份和设备配对已配置。队列与会话状态入口需要 USB/ADB；电脑关闭后，供电和网络正常的开发板继续转发。

首次配置参见 README、COS-SETUP、SECURE-PACKAGE。旧 05/09/10 测试入口可能发送真实群消息，正常使用无需运行；不要在板端已经正式发送时另外启用电脑发送端。

当前默认启用轻量检测，按网站 schedule 调整频率。队列状态会显示检测模式、最近结果和下次间隔；无变化时已有重试与会话更新照常处理。
